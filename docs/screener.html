計算規則
  • 相對變化 ＝（本季 − 比較季）÷ |比較季| × 100%，例：毛利率 30% → 33% 為 +10%，不是 +3 個百分點。
  • 基期為負/近零：比較季比率 ≤ 0 或 |比較季| < 1 個百分點時，相對變化沒有意義，不計算，改顯示百分點差並加註標記；只要設定了該項上下限，這類公司一律不納入（找轉虧為盈請用「轉虧為盈」條件）。
  • 連續成長 N 季：最近 N 季每一季都高於前一季（缺季即中斷），最多 8 季。
  • 三率同步：選定的上季、去年同季、連續成長條件，毛利率、營業利益率、淨利率三者都要符合。
  • 轉虧為盈：上季營業利益率（淨利率）< 0，本季 > 0。
  • 每家公司以自己最新公布的一季為本季；季別與全市場最新季不同者在名稱旁標示。單季營收為該季三個月月營收加總（任一月缺漏則空白）。
  • 空白欄位代表不設限；比率缺值的公司在設有該條件時不納入。
